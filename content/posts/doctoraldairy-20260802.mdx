## 一、模型已经走到数学家的桌边

2026年8月1日，OpenAI公布了一份249页的论文集，收录了由内部代号为 Astra 的模型完成的十项数学与理论计算机科学成果。随论文一同出现的，还有十套 Lean 形式化证书，以及一份说明这些想法如何形成的长篇材料。按照发布材料中的说法，找到十个答案所消耗的 token，按 Sol API 的价格计算，大约价值2000美元。

这十项结果分别涉及：

1. **高维球体堆积**：确定 Cohn–Elkies 线性规划在高维中的渐近强度，改进一般性的球体堆积上界。
2. **二元码与球面码**：对固定最小距离下的码大小给出指数级改进的上界。
3. **非 sofic 群**：构造一个明确的非 sofic 群，回答群论中的长期开放问题。
4. **Connes 刚性猜想**：构造具有相同群 von Neumann 代数的、两两不同构的 property-(T) 群，从而推翻相关猜想。
5. **算术电路复杂度**：建立 permanent 的无除法电路下界，并给出公式规模的相应下界。
6. **量子平行重复**：将平行重复定理推广到所有有限的双玩家纠缠博弈。
7. **最近向量问题**：从 3SAT 出发，给出欧几里得最近向量问题的近似困难性结果。
8. **Ehrhart 体积猜想**：对一类凸体证明尖锐的体积上界。
9. **多色 Ramsey 数**：证明三角形多色 Ramsey 数的超指数级下界。
10. **紧性与退化性**：反驳极值图论中的两个猜想。

当然，成果数量不等于奖项预测，模型的十项输出也不能直接和数学家的个人履历画等号。可是，如果只按数量、跨度和问题的长期开放程度来制造尺度感，那么 Astra 这次论证已经展现出接近菲尔兹奖级别的科研产出想象。

前段时间，Fable 5 在研究者设定问题、协作搜索和后续验证的链条中，以力大砖飞的方式帮助找到了雅可比猜想的三维反例。它不是一个“模型单独完成一切”的童话，但这件事进一步说明：人工智能已经能够在某些高度形式化的科学空间里，推进人类原本很难推进的搜索。

## 二、模型真正击穿的是人的稀缺性

在人类最引以为傲的智力层面，人的注意力是稀缺的。一个数学家不可能同时熟悉十几个领域，不能无限追踪一条看起来毫无希望的路线，也不能在一万个失败方案之间无成本切换。人类还受到职业激励、学术声誉和时间预算的约束。

一个年轻研究者如果沿着错误方向研究三年，这辈子可能就要完蛋，甚至还会面临非升即走、评不上教职的风险。而大语言模型每隔几个月就可能迎来一次 context 扩容，用不了多久，数学史上的高峰或许会被一个接一个地攀登。

换句话说，对于民科而言，这更是一个黄金时代。民科第一次有机会和前沿科学家站在同一条工具起跑线上。记得分析哲学学界两年前还有人嘲讽民科有相当多的“智能派数学家”，AI for Math 在当时还几乎完全不可行。没想到不到两年，数学家们瘫坐在椅子上，科学界的核弹又一次爆炸了。

> “我早就是智能派数学家了。”

真正被压低价格的，可能不是数学家的判断，而是那些可以被无限复制的前置劳动：搜索、检索、试错、改写、形式化，以及把一个想法推到可验证状态所需要的大量耐心。

## 三、LLMs can’t jump：科学发现究竟跳在哪里

正如陶哲轩所提醒的那样，科研正在被分解成问题选择、知识检索、方案搜索、结果验证、意义解释和共同体承认等不同环节。人人都可以生成一篇长得像论文的东西，恰恰意味着“长得像论文”将迅速失去价值。

令人忍俊不禁的是，就在 Astra 公布前不久，Google DeepMind 研究员 Tom Zahavy 发表了一篇题为 [《LLMs can’t jump》](https://philsci-archive.pitt.edu/28024/1/Scientific_Invention_Position_Paper%20%2817%29.pdf) 的立场论文。

这篇论文借用了爱因斯坦写给 Maurice Solovine 的一幅图。按照这种描述，科学发现不是一条从数据直接通向理论的直线，而是一个循环：人从感官经验出发，通过一次无法被纯逻辑还原的“跳跃”，建立新的公理体系，然后再从这些公理中演绎出可以接受经验检验的结果。

Zahavy 据此区分了三种推理：从案例和结果中总结规则的归纳，从规则和案例推出结果的演绎，以及为了说明一个意外结果而发明新假设的溯因。论文承认现代模型正在掌握归纳和演绎，**却认为它们缺少从经验世界跃迁到新公理的溯因机制**。

广义相对论就是它选择的案例：模型或许能从爱因斯坦的前提出发推导方程，却无法仅凭当时稀少的观测资料发明那些前提。论文最后把解决方案落在具有物理一致性和多模态感知能力的世界模型上。这个落点或许略显牵强，但它指出的那种前瞻性或“空想性”的思考，仍然非常重要。毕竟某些天赋异禀的人，甚至能够直接在大脑里做思维实验。

## 四、Astra 出现以后：数学内部的“跳跃”

然后，Astra 带着十项成果出现了。

数学问题通常已经给出了公理、定义和需要证明的命题，Lean 又提供了明确的验证器。Astra 不需要像爱因斯坦那样从电梯下坠的想象中重新规定引力是什么。它活动在一个高度符号化、边界明确并且可以机械检查的世界里。

但 Astra 至少动摇了一种观点：似乎模型只能重复已有知识，而真正的创造永远属于人类。

这件事的关键，也许不在于它是否完成了人类意义上的“跳跃”，而在于我们过去把数学家的创造性想象得过于整体化了。一个所谓的新证明，可能包含问题选择、文献检索、局部猜测、方案组合、失败路线的淘汰、形式化和最后的意义解释。模型未必承担了所有环节，但它已经能够在其中若干环节上大规模工作，并且把原本昂贵的搜索变成一种可以并行展开的资源。

## 五、从 Known-Known 到 Unknown-Unknown

我前段时间和朋友聊天时，他曾经和我说过，理论界总在争辩究竟是 “Theory Drive” 还是 “Data Drive”，这是一个没有意义的问题。关键是要识别，在现在的知识生产中，有哪些知识是 `Known-Known`，哪些是 `Unknown-Unknown`，又有哪些是 `Unknown-Known`、`Known-Unknown`。

可以先粗略地这样理解：

| 类型              | 简单理解                               | 模型目前更容易发挥的地方             |
| ----------------- | -------------------------------------- | ------------------------------------ |
| `Known-Known`     | 已知的已知                             | 检索、压缩、复述与标准化             |
| `Known-Unknown`   | 已知自己不知道的东西                   | 定向检索、补足知识和搜索方案         |
| `Unknown-Known`   | 已经存在、但尚未被当前研究者调用的知识 | 跨文献连接、隐含关系发现和组合       |
| `Unknown-Unknown` | 还没有被提出的问题、概念或观察角度     | 目前仍然最依赖问题意识、经验和共同体 |

LLM 似乎可以在 `Unknown-Known` 和 `Known-Unknown` 上大放异彩，但是对于 `Unknown-Unknown` 仍然几乎束手无策。诚然，这里可能会涉及知识社会学或更复杂的东西。关于何谓 “Known” 和 “Unknown”，不同业界可能有不同定义；但从“创造”这个概念来说，不同科学中的创造并不是同一种东西。

数学中的跳跃，可以发生在符号系统内部；物理学中的跳跃，往往需要模拟、实验和感知；社会科学中的跳跃，则还涉及概念、意义、制度和价值。问题不再是 LLM 能不能跳，而是每一个学科的地面由什么构成，它的悬崖在哪里，以及什么东西有资格充当落地后的验证器。

## 六、AI for Science 重新分配科研的稀缺性

总的来说，AI for Science 最重要的变化，是对科研过程中稀缺性资源的定义进行了重新分配。

在目前的科研体系中，我们过于看重“结果”端。换句话说，职称和各种帽子的评定需要成果，成果往往又是专利或论文，而这些又与“结果”密切相关。然而科研是一个全过程，除了结果，还有“假设”“推导”“探索”等等，但是所有的果实都被“结果”夺取了。

过去，假设很稀缺，推导很昂贵，文献检索很慢，计算能力有限。未来，模型可以批量产生假设、证明草稿、代码、模型和实验方案。问题将从“没有结果”变成“结果太多”。

> 科研真正稀缺的，可能不再是答案，而是值得被回答的问题、能把搜索组织起来的结构，以及对结果究竟意味着什么的判断。

如果按照目前期刊的运作机制，我估计不出三年，同行评审制度将会被迅速吞没，大量“成果”论文将会铺天盖地地涌现。数学是最早受到冲击的，因为数学本身拥有近乎理想的反馈机制：只要设置严格的 `Prompt` 和 `Agent`，Lean 内核不关心证明者是教授、研究生还是一块显卡，它只检查每一步是否符合规则，然后输出结果。

这也意味着，期刊和学术共同体必须重新回答一个问题：当证明本身可以被规模化生产时，我们究竟要评价什么？是结果的新颖性，路线的原创性，问题的价值，解释的清晰度，还是组织一组人和机器持续推进问题的能力？

## 七、结果之外，科研共同体还要评价什么

在我看来，“结果”固然重要，但是科研是一个全流程的智力劳动。提出问题的能力、验证问题的能力、解释结果的能力，甚至科研人员的管理与组织，都应该被纳入考量。只是它们的权重几何、利益如何分配，就有待大佬们商议了。

也许未来最稀缺的不是“会不会写出一篇论文”，而是能不能在答案泛滥之后，仍然辨认出哪些问题值得继续追踪，哪些证明值得被理解，哪些结果足以改变我们对一个领域的想象。
