# ADR 0002：MDX 唯一运行内容源

日期：2026-10-07。状态：本地实现并验证，正式网站尚未发布。

用户明确要求移除不再需要的远程内容平台集成。ADR 0001 中的可选草稿或导入 adapter 不再作为运行代码维护；历史导入结果及迁移元数据保留。

应用只从本地 MDX 构建页面，书卷为当前唯一主题。移除旧数据访问层、OAuth、未启用的登录后台、旧正文 renderer 和相关依赖；公式及图片缩放独立保留。

列表和导航不携带正文，全文搜索和文章页按需要取得正文。页面变化随 Git 发布，不使用定时增量生成；默认页面堆缓存关闭。统计与实时数据库仍由独立服务负责。

当前保留 standalone 发布协议，不将此源码清理与未经验证的静态托管切换捆绑。纯静态输出需另行核验任意搜索路径、API、跳转及现有带签名统计回源。
